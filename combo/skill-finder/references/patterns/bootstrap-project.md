# Pattern: bootstrap-project

Install tooling and scaffold a new project.

## Trigger Phrases

* bootstrap a new project
* set up a new project
* start a new project
* scaffold a project
* quickstart

## Required Steps

1. **quickstart.** Skill: `quickstart`. Purpose: install tooling and set up the machine.
2. **bootstrap.** Skill: `bootstrap`. Purpose: scaffold the project structure.

## Handoff Notes

* quickstart to bootstrap: pass the detected OS and the chosen stack.
