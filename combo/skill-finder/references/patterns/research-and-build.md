# Pattern: research-and-build

Competitive analysis, ideate features, spec the top idea, and build it.

## Trigger Phrases

* research and build
* competitive analysis and new features
* what should we build next
* gap analysis

## Required Steps

1. **research.** Skill: `research`. Purpose: competitive gap analysis plus feature ideation.
2. **spec.** Skill: `spec`. Purpose: turn the top idea into a spec.
3. **build.** Skill: `skills-hub-registry-story-implementer`. Purpose: implement the spec.

## Handoff Notes

* research to spec: pass the top ranked feature idea.
* spec to build: pass the spec file path.
