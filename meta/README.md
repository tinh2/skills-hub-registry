## About

Meta skills maintain and improve the skill system itself. They form a self-improving feedback loop:

```
/recall → /metrics → /evolve → /promote
```

- `/bootstrap` — Scaffold new projects from templates
- `/evolve` — Patch skills based on recall/metrics findings  
- `/extract-template` — Capture a project's pipeline as a reusable template
- `/promote` — Detect cross-project patterns and promote to global conventions
